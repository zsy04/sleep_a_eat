#   Markdown学习

## 一 标题

通过"#"来设定标题

一级标题一个"#"，二级标题两个"#",其余的以此类推

### 实例：

"# 一级标题"

"## 二级标题"

共有可以设置六级标题。

## 二 字体

字体两边加"**"可以将字体转变为粗体

字体两边加"*"可以将字体转变为斜体

字体两边加"***"可以将字体转为粗体加斜体

字体两边加"~~"可以将字体加上删除横线

### 实例：

粗体

**hello,word!**

斜体

*hello,word!*

粗体加斜体

***hello,word!***

删除横线

~~hello,word!~~



## 三 引用

">"加句子为引用

### 实例

## 四 分割线
